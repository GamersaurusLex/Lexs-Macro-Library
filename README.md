# Lex's Macro Library

Enable this module, open **Compendium Packs → Lex's Macros**, and drag an
entry to a hotbar. Each macro states its system and permission requirements.

Current entries:

- **Populate Common Divine Spells** for PF2e prepared Divine spellcasters. It
  uses a selected character token when a GM runs it; otherwise it resolves an
  owned eligible character for the player running it.
- **Add Party to Scene** adds party Actors to the active Scene from their
  prototype tokens. In PF2e, it uses the Party actor; in D&D 5e, it uses
  character Actors from the `The Party` folder; in Delta Green, it places every Actor from the
  `Party` folder. In PF2e and D&D 5e, it offers extras from any Actor folder
  whose name includes Familiar or Companion.
- **WASD Movement Toggle** switches between Foundry's defaults and a movement
  layout using WASD, arrow keys, and the number pad.
- **Open Award Panel** opens the Lex's Variant Rules award panel for the GM.
- **Basic Actions for a Token** lets the GM pick a token on the viewed scene
  and open PF2e Workbench's Basic Action Macros for it.
- **Recall Knowledge** opens Lex's Variant Rules' scene-aware subject and
  target picker, then runs PF2e Workbench's normal Recall Knowledge workflow.
