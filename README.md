# Lex's Macro Library

Enable this module, open **Compendium Packs → Lex's Macros**, and drag an
entry to a hotbar. Each macro states its system and permission requirements.

Current entries:

- **Populate Common Divine Spells** for PF2e prepared Divine spellcasters. It
  uses a selected character token when a GM runs it; otherwise it resolves an
  owned eligible character for the player running it.
- **Add Party to Scene** adds all player characters to the active Scene. In
  PF2e, it can also include actors from folders whose names include Familiar or
  Companion. In Delta Green, it places every Actor from the `Party` folder.
- **WASD Movement Toggle** switches between Foundry's defaults and a movement
  layout using WASD, arrow keys, and the number pad.
