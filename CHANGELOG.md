# Changelog

## 0.1.5

- Added **Recall Knowledge**, which opens Lex's Variant Rules' scene-aware
  Recall Knowledge picker before running PF2e Workbench's normal Recall
  Knowledge workflow.

## 0.1.4

- Added **Open Award Panel** and **Basic Actions for a Token** with custom
  hotbar icons. Both macros are GM-only.

## 0.1.3

- Updated **Add Party to Scene** for Delta Green: it now places Actors from the
  `Party` folder and omits the PF2e familiar/companion picker.

## 0.1.2

- Added purpose-built SVG icons for Add Party to Scene, Populate Common Divine
  Spells, and WASD Movement Toggle.

## 0.1.1

- Replaced **Add Party to Scene** with the tested Season of Ghosts version. It uses the PF2e Party actor when available, offers individual familiar/companion selections, remembers those selections per user and world, and places prototype tokens safely within scene bounds.

## 0.1.0

- Initial release with the prepared Divine spell helper, Add Party to Scene,
  and WASD Movement Toggle macros.
